# GoreeCloud Network Dashboard Branding

All branding authority belongs to `GoreeCloud/goreecloud-branding-assets`.

This dashboard is part of GoreeCloud Network. Approved Network product artwork is stored at `products/network/app-icon.svg`. Dashboard-local artwork is a synchronized derivative only. Any dashboard-specific logo, icon, illustration, or promotional asset must be created and approved in the unified branding repository before being synchronized here.

Branding does not establish network authority, runtime acceptance, or release claims.
